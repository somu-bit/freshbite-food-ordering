# 🍕 FreshBite - Online Food Ordering Application

FreshBite is a responsive, interactive web application for ordering food online. Users can browse popular categories, filter items by dietary preferences, add dishes to a slide-out shopping cart, and place simulated orders.

## 🚀 Live Demo
[View Live Site on GitHub Pages](https://somu-bit.github.io/freshbite-food-ordering/)

---

## ✨ Features

* Dynamic Food Menu: Rendered dynamically using JavaScript object data.
* Category & Dietary Filtering: Instantly filter items by category (Pizza, Burgers, Pasta, Sides) or type (Veg / Non-Veg).
* Interactive Shopping Cart: Slide-out drawer to add/remove items and calculate real-time totals.
* Local Storage Persistence: Cart items persist even after refreshing the page.
* Responsive Layout: Tailored for both desktop and mobile viewports with custom UI themes.

---

## 🛠️ Tech Stack

*HTML5: Semantic structure and access control.
*CSS3: Custom CSS variables, Grid/Flexbox layouts, and slide-out animations.
*JavaScript (ES6): State management, array filtering, local storage, and DOM manipulation.
*Git & GitHub Pages: Version control and continuous deployment.
